# SpeechFlow

Программа для распознавания речи в текст. Работает полностью локально — ничего не отправляется в интернет, весь звук обрабатывается прямо на вашем компьютере.

## Возможности

- Распознавание речи из аудио и видео в текст
- Работа полностью офлайн после загрузки модели — конфиденциальность гарантирована
- Поддержка GPU (CUDA) для ускоренной обработки на видеокартах NVIDIA
- Несколько моделей на выбор — от быстрой и лёгкой до максимально точной
- Автоматическая проверка и коррекция орфографии в распознанном тексте
- Экспорт готового текста в документ Word (.docx)
- Мониторинг загрузки GPU прямо в приложении

## Системные требования

- Windows 10/11 (64-бит)
- **Установленный .NET 8 Desktop Runtime** — без него программа не запустится. Скачать можно здесь: [dotnet.microsoft.com/download/dotnet/8.0](https://dotnet.microsoft.com/download/dotnet/8.0) (выбирайте пункт "Desktop Runtime" для x64)
- Для ускорения через видеокарту — NVIDIA GPU с поддержкой CUDA (опционально, без неё программа тоже работает, просто медленнее)
- Свободное место на диске — от 100 МБ до 3 ГБ в зависимости от выбранной модели распознавания

## Установка и запуск

1. Скачайте архив с последним релизом
2. Распакуйте в любую папку — установка не требуется
3. Убедитесь, что установлен .NET 8 Desktop Runtime (см. выше)
4. Запустите `SpeechFlow.exe`

## Первый запуск

При первом запуске нужно скачать модель распознавания и, если планируете использовать GPU — CUDA-компоненты. Всё это делается прямо внутри программы в один клик, ничего скачивать вручную не нужно.

Доступные модели (чем больше — тем точнее, но медленнее):

| Модель | Размер | Когда использовать |
|---|---|---|
| tiny | ~75 МБ | Быстрые черновые расшифровки |
| base | ~140 МБ | Баланс скорости и качества |
| small | ~460 МБ | Хорошее качество для большинства задач |
| medium | ~1.5 ГБ | Высокая точность |
| large-v3 | ~3 ГБ | Максимальная точность |

## Как пользоваться

1. Загрузите аудио или видео файл в программу
2. Выберите модель распознавания в настройках
3. Запустите обработку и дождитесь завершения
4. Проверьте и при необходимости отредактируйте текст — орфография подсвечивается автоматически
5. Экспортируйте результат в Word одним нажатием

## Частые проблемы

**Программа не запускается / пишет про .NET Runtime**
Значит не установлен .NET 8 Desktop Runtime — установите по ссылке выше и перезапустите.

**Не работает ускорение на видеокарте**
Убедитесь, что скачаны CUDA-компоненты в настройках программы, и что у вас установлены актуальные драйверы NVIDIA.

**Модель долго скачивается**
Модели скачиваются напрямую с Hugging Face, скорость зависит от вашего интернет-соединения. Большие модели (medium, large-v3) могут занять продолжительное время.
